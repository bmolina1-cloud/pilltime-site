# pilltime-site

Public landing page + legal documents for [PillTime](https://github.com/bmolina1-cloud/pilltime).

Hosted via GitHub Pages so Apple's App Store Connect "Privacy Policy URL" and
"Support URL" fields point to real, hostable URLs.

Pages:
- `index.html` — landing page
- `privacy.html` — Privacy Policy (linked from App Store Connect)
- `terms.html` — Terms of Use
- `disclaimer.html` — Medical Disclaimer
- `support.html` — Support page (linked from App Store Connect)

The same legal text is also embedded inside the app itself for offline access
(see [src/services/legal.js](https://github.com/bmolina1-cloud/pilltime/blob/main/src/services/legal.js)).
